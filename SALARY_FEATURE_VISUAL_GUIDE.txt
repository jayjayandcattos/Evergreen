    ✅ WHO CAN EDIT?
       → Admin only (HR can view but not edit)

    ✅ WHERE TO EDIT?
       → HRIS Employees Page → Click Edit → Scroll to Salary Information

    ✅ WHAT GETS CALCULATED?
       → Daily Rate = Monthly ÷ 22
       → Hourly Rate = Daily ÷ 8

    ✅ WHERE DOES IT SHOW?
       → Payroll Management → Select Employee → SALARY RATES card

    ✅ HOW FAST?
       → Instant! No sync delay, same database

    ✅ Solution: Make sure you clicked SAVE after entering salary

    ✅ Solution: These are auto-calculated, only edit Monthly Salary

    ❌ Problem: Changes not reflecting
    ✅ Solution: Refresh the Payroll Management page
